Best Store:

Best Stire is an e-commerce web application built with Django.

Features:

- Product categories
- Product search
- Product details
- Shopping cart
- User registration
- Login and logout
- Django admin panel

Technologies:

- Python
- Django
- HTML
- CSS
- Bootstrap
- JavaScript
- SQLite
- Git

Installation:

Create virtual environment:

python -m venv .venv

Activate virtual environment:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run migrations:

python manage.py migrate

Start the server:

python manage.py runserver
